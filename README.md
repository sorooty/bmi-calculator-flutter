# BMI Calculator 💪

![ImagePres](assets/images/BMI%20CALC%20MainPage.png)

## Objective

To explore and master the Flutter framework, I developed this project: a Body Mass Index (BMI) Calculator. This project allowed me to deepen my understanding of Flutter and improve my skills in designing beautiful and functional user interfaces with custom widgets.

## What You Will Create

In this project, I created a simple yet elegant BMI Calculator app, where users can input their details to calculate their BMI. The app features a multi-screen design with a focus on custom styling for a smooth user experience.

![Finished App]()

## What I've Learned :

- How to customize Flutter widgets to create unique and attractive designs.
- How to create multi-screen applications using Flutter Routes and Navigator.
- How to refactor and extract Flutter widgets for cleaner and reusable code.
- How to pass functions as parameters to create more modular code.
- How to use the `GestureDetector` widget for custom interactions.
- How to apply custom color palettes using hex codes.
- How to use Dart Enums and the Ternary Operator for better control flow.
- The difference between `const` and `final` in Dart, and when to use each.
